Local Exposure Mapper

ANAS-Local

ANAS-Local is the local student model for ANAS Sentinel: a Qwen3-8B exposure mapper that runs through Ollama on Mac and converts event text plus metadata into strict ANAS ExposureStruct JSON.

Local Engine Ollama

Packaged as a GGUF Q4_K_M model for local Mac inference.

Student Model Qwen3-8B

Distilled from the larger ANAS exposure-mapping workflow with QLoRA and Unsloth.

Core Task JSON

Maps official or private event text into ANAS ExposureStruct output for downstream warning engines.

The problem

The original ANAS pipeline can use hosted large-model calls, but warning systems often need privacy, controllable latency, and reproducible local preprocessing. Sending every document to an external endpoint is not always the right operating mode.

The idea

ANAS-Local narrows the model's job to one auditable transformation: event text and metadata in, schema-controlled exposure JSON out. It is a component for risk-warning infrastructure, not a trading bot or a market-prediction system.

Model Pipeline

From ANAS exposure records to a local Ollama model.

01

ANAS Outputs

Use accepted exposure structs from the larger ANAS event-intelligence workflow.

Training data starts from structured ANAS v1 outputs rather than raw prediction labels.
02

SFT Dataset

Build prompt-completion examples for ExposureStruct generation.

The dataset teaches the student model the ANAS schema, category universe, currency proxies, and rationale style.
03

QLoRA Train

Fine-tune unsloth/Qwen3-8B with Unsloth on the exposure-mapping task.

The LoRA adapter captures the narrow event-to-exposure behavior without retraining a full base model.
04

GGUF Export

Export the local Mac artifact as Q4_K_M GGUF for Ollama.

The release package includes split GGUF archives and SHA256 checksums for reproducible installation.
05

Guarded Eval

Evaluate JSON parseability, schema validity, repair rate, and exposure overlap.

A schema-repair guard keeps malformed local outputs from entering downstream warning logic.

What was measured

The evaluation checks whether the local model returns parseable JSON, follows the ANAS schema, and overlaps with the larger model's top category and currency exposures.

Why the repair rate matters

Only 1.22% of outputs needed schema repair in the guarded run, while the final schema-valid rate reached 100%. That makes the model practical as a controlled preprocessing layer.

What the score means

Top-3 overlap near 0.9 means the student model usually preserves the main exposure neighborhood, while small relevance-score drift remains visible for later tuning.

Run Guide

Minimal local setup path for release users.

  1. Install Ollama Local engine
    Install Ollama, then confirm it is available with ollama --version.
  2. Download release assets GGUF parts + checksum
    Place the split GGUF archive parts and SHA256SUMS in a local model folder.
  3. Reassemble and verify Archive integrity
    Combine the parts, run shasum -a 256 -c SHA256SUMS, and extract the archive.
  4. Create the Ollama model anas-exposure-qwen3-8b-phase1
    Register the Modelfile with Ollama, then run the model and ask for strict ANAS ExposureStruct JSON.

Boundaries

ANAS-Local is a local exposure mapper, not an autonomous decision system.

No trading claim

Preprocessing only.

The model does not execute trades, predict markets directly, or provide financial advice.

Schema control

Strict output shape.

Prompts and evaluators require one JSON object using the ANAS schema keys and exposure universes.

Local-first

Privacy-aware local engine.

Private notes and official documents can be mapped locally before downstream warning engines consume the structured state.

Next Direction

From Phase 1 student model to a stronger local warning-system component.

The next version can expand the training corpus, improve relevance-score calibration, and add stronger regression tests around category, currency, horizon, and rationale fields.

ANAS-Local is designed to sit beside the full ANAS pipeline: the hosted pipeline can explore and judge new event data, while the local student provides privacy-preserving inference for repeated warning-system preprocessing.
